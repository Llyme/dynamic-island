Not another dynamic island.

A small pill with a pair of eyes at the top of your Windows screen. It tells you what is playing, which game you are in, what is downloading, and when a Claude Code session needs you.

Download for Windows How to run it

It is live. Move your mouse over the desktop and the eyes follow it.

What it does

A glance, instead of a window.

Everything lives in one pill that stays out of your way. It lights up only when something happens by itself, and it is built to never make the computer lag.

LLM Detection

Claude Code, watched for you.

Every running Claude Code session gets its own card, in VS Code, the terminal or inside WSL. The ring around the tile is its context window. When one needs you or finishes, the island drops down to tell you.

  • A phone rings on a session that needs your approval, and it jumps to the top.
  • A finished session waits with a check until you look at it, then it clears.
  • One at a time in the queue, a "needs you" first. Quiet while a game runs or its window is already in front.
Make it yours

Install

Two minutes, no account.

  1. Download the installer from the latest release and run it. Windows 10 or 11 (the WebView2 runtime comes with Windows 11).
  2. Rest your cursor on the top edge of a monitor. A glow builds up and the island lands. Click it to expand the hub; right-click to pin it.
  3. Open Settings from the tray icon. Turn on notification access in Windows if you want other apps' notifications to show.

Or build it yourself. It is a Rust backend with a plain JavaScript frontend, built with Tauri v2.

cd src-tauri
cargo tauri dev      # run it
cargo tauri build    # release exe and NSIS installer
NADI. Windows only, for now.
